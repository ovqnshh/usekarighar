# Build Karighar customer prototype

## Experience
- Create a warm, mobile-first Karighar home page centered on a natural-language “Ask Karighar” composer and Build, Renovate, and Fix entry points.
- Use a craftsman-modern visual system with terracotta, warm neutrals, editorial typography, real project imagery, and clear trust signals.
- Add shared desktop navigation and a compact mobile navigation pattern.

## Core flow
- Turn the Ask Karighar prompt into a short understanding state, then an editable Project Brief with all requested estimates and labels.
- Continue into matched professional results with working sort and filter controls.
- Let customers open a complete professional storefront, request a quote, and move into a mock hired-project workspace.
- Add working project tabs for overview, messages, photos, and cost breakdown.

## Pages
- `/` — discovery and Ask Karighar
- `/professionals` — matched professionals
- `/professionals/$id` — professional storefront
- `/project` — hired-project workspace

## Technical details
- Keep all data mocked in the front end; no login, payments, or live matching.
- Build reusable navigation, professional, badge, and project UI pieces.
- Add route-specific sharing and search metadata.
- Verify loading, editing, filters, profile navigation, quote flow, tabs, and responsive layouts in the running preview.
